# Draw Goffy ルール仕様

このファイルがゲームルールの唯一の正（Single Source of Truth）です。
実装は `scripts/game_rules.gd`（進行・戦闘解決）と `scripts/card_store.gd`
（カードの正規化・レアリティ）にあり、`tests/rules_smoke.gd` が期待値を固定しています。
ルールを変えるときは、まずこのファイルを更新してから実装とテストを合わせます。

READMEの「現在の実装範囲」は"できること一覧"、`design_notes.md` は"決定と未決事項"。
ルールそのものの定義はここに集約します。

---

## 1. 基本パラメータ

| 項目 | 値 | 定数 |
| --- | --- | --- |
| 初期HP | 40 | `START_HP` |
| 手札の上限 | 9 枚 | `HAND_SIZE` |
| 所持カード上限（手札＋習得奇跡） | 18 枚 | `MAX_CARD_COUNT` |
| 属性 | 7 種 | `VALID_ATTRIBUTES` |

- カードを消費したら、手札を 9 枚まで補充する（所持上限 18 枚を超えない範囲で）。
- 属性は `none` / `fire` / `water` / `wood` / `earth` / `light` / `dark` の7種類のみ。

---

## 2. カードの構造

カードは `card_store.gd` の `_normalize_card` で必ず正規化される。プレイヤーが
自作したカードも、読み込み・投稿の時点で以下のルールに丸められる。

| フィールド | 取り得る値 | 既定 |
| --- | --- | --- |
| `type` | `weapon` / `armor` / `miracle` / `special` | `weapon` |
| `effect` | `attack` / `buff` / `guard` / `reflect` / `heal` / `instant_death` | `attack` |
| `target` | `enemy` / `self` / `all_enemies` / `all_players` | `enemy` |
| `attribute` | 7属性のいずれか | `none` |
| `power` | 整数（回復の負数はダメージ扱い） | 10 |
| `chance` | 発動率 0〜100（%） | 100 |
| `effect_mode` | `all`（全効果発動） / `random_one`（1つ抽選） | `all` |
| `effects` | 効果エントリの配列（複合カード用） | 単一効果から自動生成 |
| `tags` | `full_reflect` / `builtin` など | `[]` |
| `rarity` | 自動計算（下記) | — |

### 種類（type）の意味

`type` は効果・対象を制限しない（`special` でも `guard` を持てる等）。挙動に効くのは次の3点だけ：

- **`armor`** のみ、防御フェーズで `attack` 効果を「反撃」として使える。
- **`miracle`** は使っても消費されず「習得」される（→ 第10章）。
- レアリティからドロー山のコピー枚数が決まる（→ 第11章）。

### 複合効果（effects / effect_mode）

1枚に複数の効果を持たせられる。使用フェーズに合う効果だけが発動する（→ 第8章の表）。

- `effect_mode = all` … 条件に合う効果をまとめて全部発動する。
- `effect_mode = random_one` … `weight` の比で1つだけ抽選して発動する。

### 発動率（chance）

カード全体と、各効果エントリの両方に 0〜100% の発動率を持てる。
全体攻撃・全体回復は**対象者ごと**に、防具は**防具ごと**に個別判定する。

### 廃止された値の読み替え

- `effect: multi_attack` → `effect: attack` ＋ `target: all_enemies`。
- `target: all` / `ally` → `self`。
- `heal` だけのカードは属性相性に関与しないため `attribute` は `none` に固定。

## 3. ゲームの流れ（フェーズ）

```
action ──(攻撃/支援を出す)──▶ defense ──(防御 or パス)──▶ result ──┐
   ▲                                                              │
   └──────────────── continue_after_result ◀──────────────────────┘
                        （反撃・全体対象の続き・次ターンへ）
```

- **action**: 手番プレイヤーがカードを出すか、祈るか、パスする。
- **defense**: 攻撃/支援の対象が防御カードを出すか、パスする。
- **result**: 戦闘結果の演出。`continue_after_result` で次へ進む。
- **game_over**: 生存者が1人以下になったら決着（→ 第12章）。

手番は生存プレイヤーの間を順に回る。倒れた（切断含む）プレイヤーは飛ばす。

---

## 4. 行動フェーズ

手番プレイヤーができること：

### 4.1 攻撃のセット（攻撃／攻撃アップ）

`play_action_cards` は複数枚をまとめて「セット」として出せる。

- **攻撃カード（`attack`）は1回に1枚まで**。2枚重ねようとするとセット全体が弾かれ、何も消費しない。
- **攻撃アップ（`buff`）は何枚でも重ねられる**。威力は攻撃＋攻撃アップの合計。
- 攻撃アップは**単独でも攻撃**として使える（威力 = 攻撃アップの合計）。
- 攻撃・攻撃アップに、それ以外の効果（回復・防御など）は混ぜられない。

複数防具で防御するのと同じ操作感で、複数カードを重ねて1回の攻撃にする。

### 4.2 単発の効果

攻撃を含まないカードは**1枚だけ**単発で出す（`heal` / `guard` / `reflect` / `instant_death` など）。

### 4.3 祈り（pray）

- 攻撃カードも攻撃アップも手札・習得奇跡に**持っていない**ときだけ祈れる。
- カードを1枚引いてターンを終える（所持上限に達していても、ターン終了としては成立する）。

### 4.4 パス（pass_action）

何もせずターンを終える。

---

## 5. 攻撃の威力と属性合成

### 威力

出したカード（攻撃＋攻撃アップ）の `power` の合計が攻撃の威力になる。

### 攻撃側の属性合成（`_combined_offensive_attribute`）

- **光（`light`）はワイルドカード**。他属性と重ねると、その属性の攻撃になる。
- 光以外の属性が**2種類以上**混ざると、無属性（`none`）になる。
- 全部が光なら光。全部が無属性なら無属性。

---

## 6. 防御フェーズ

攻撃/支援の対象になったプレイヤーが応答する。

### 6.1 防具の選択

- **属性条件を満たす防具だけ**選べる（→ 第7章の属性防御表）。
- 複数の防具を重ねて出せる。防御値（`guard`/`reflect` の `power`）は合算。
- 防御値の合計が攻撃の威力以上ならダメージ 0。
- ダメージ = `max(0, 攻撃威力 − 防御値)`。

### 6.2 事前の防御準備

行動フェーズで先に使った `guard` / `reflect` は、次に攻撃されたときに自動で適用される。
ただし**その攻撃の属性を防げる属性**のときだけ発動する（防げない属性なら不発）。
発動後は解除される。

### 6.3 反射（reflect）

- 通常の反射：跳ね返すダメージ = `min(攻撃威力, 防御値)`。
- **完全反射**（`reflect` 効果＋`full_reflect` タグ）：攻撃威力をそのまま跳ね返す。
  さらに、回復・支援などの非攻撃効果も**使用者へ返せる**唯一の手段。

### 6.4 反撃（counter）

`armor` かつ `attack` 効果を持つ防具で防御すると、防御解決後に「反撃」が用意される。
`continue_after_result` で、防御側から攻撃側への新たな攻撃として発動する。

---

## 7. 属性防御ルール

攻撃属性に対し、防御に使える／通用する属性は次の通り（`_attribute_can_defend`）。

| 攻撃属性 | 防げる防具の属性 | 備考 |
| --- | --- | --- |
| `none`（無） | すべて | どの防具でも防げる |
| `fire`（火） | `water`・`light` | |
| `water`（水） | `fire`・`light` | |
| `wood`（木） | `earth`・`light` | |
| `earth`（土） | `wood`・`light` | |
| `light`（光） | **なし** | 防御・反射ともに不能 |
| `dark`（闇） | すべて | ただしダメージが1でも通れば**即死** |

- **光攻撃**：どの防具でも防御条件を満たさないため、防具も完全反射も選べない（貫通）。
- **闇攻撃**：防具を選ぶこと自体は可能。**完全に防ぎ切れば無傷**だが、ダメージが少しでも
  残ると対象のHPを0にする（即死化）。反射で跳ね返した場合の反射ダメージは通常計算のまま
  （即死化しない）。

複数属性の防具を混ぜると、表示上の防御属性は「`mixed`」になる。

---

## 8. 効果リファレンス

| 効果 | 内容 | 有効なフェーズ |
| --- | --- | --- |
| `attack` | 威力ぶんのダメージ | action（攻撃）／`armor`なら防御時の反撃 |
| `buff` | 攻撃威力を加算（攻撃アップ、単独でも攻撃） | action |
| `heal` | HP回復（負数はダメージ、最大HPまで） | action |
| `instant_death` | 対象のHPを0にする | action |
| `guard` | 防御値を用意（事前使用も可） | defense |
| `reflect` | 防御しつつ反射（`full_reflect`で完全反射） | defense |

フェーズごとに、そのフェーズで意味を持つ効果だけが発動する（複合カードは使い分けされる）。

---

## 9. 全体対象（all_enemies / all_players）

- **敵全体攻撃**（`target: all_enemies`）：1枚を敵全員へ順番に適用する。各対象が
  個別に防御でき、発動率も対象ごとに振り直す。攻撃アップを重ねた合算威力で全員を撃つ。
- **全体支援**（`target: all_players`）：生存者全員（自分を含む）へ順番に適用する。
  例：全体回復は全員を最大HPの範囲で回復する。

いずれも1人ぶんが解決するたびに `continue_after_result` で次の対象へ進む。

---

## 10. 奇跡（miracle）と所持上限

- `miracle` カードは使っても捨て札にならず、`learned_miracles`（習得済み奇跡）へ移り、
  以降**何度でも再利用**できる。
- 手札（通常カード）と習得奇跡を合わせた所持数は **18 枚が上限**。
- 上限に達しているときは、カードを消費しても補充が止まる。

---

## 11. レアリティとドロー山

### 自動レアリティ（`auto_rarity`）

効果の強さからレアリティを自動計算する。基礎点 = `|power|` ＋ 効果ボーナス：

| 効果 | ボーナス |
| --- | --- |
| `instant_death` | +45 |
| `reflect` | +18 |
| `buff` | +10 |
| `guard` | +8 |
| `heal` | +6 |

- 全体対象（`all_enemies` / `all_players`）は各効果に **+15**。
- `effect_mode = all` は全効果の合計、`random_one` は最大値を採用。
- 合計に発動率（`chance`%）を掛けた値が最終スコア。

| 最終スコア | レアリティ | ドロー山のコピー枚数 |
| --- | --- | --- |
| 45 以上 | `legendary` | 1 |
| 30〜44 | `rare` | 3 |
| 16〜29 | `uncommon` | 5 |
| 15 以下 | `common` | 8 |

### ドロー

- 開始時に seed を生成し、各カードをレアリティぶん複製してシャッフルし山札にする。
- 山札が尽きたら捨て札をシャッフルして山札に戻す。
- 対戦用の共有カードは、個人コレクション（`cards.json`）とは分離される。

---

## 12. 勝敗・切断

- 生存者が**1人だけ**になったら、そのプレイヤーの勝利（`game_over`）。
- 生存者が**0人**なら引き分け。
- 試合中に切断したプレイヤーは脱落（HP0・生存フラグ解除）扱いにして、ターンを進める。
