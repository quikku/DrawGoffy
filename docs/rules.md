# Draw Goffy ルール仕様

このファイルがゲームルールの唯一の正（Single Source of Truth）です。
実装は `scripts/game_rules.gd`（進行・戦闘解決）と `scripts/card_store.gd`
（カードの正規化・レアリティ）にあり、`tests/rules_smoke.gd` が期待値を固定しています。
ルールを変えるときは、まずこのファイルを更新してから実装とテストを合わせます。

この文書には、現在の実装に加えて、話し合いで確定し今後実装する予定の仕様も含みます。
本文に「設計中」「未確定」と明記した項目以外は確定仕様です。現行コードがまだ追従していない
項目は、この文書を基準に順次実装・テストを更新します。

READMEの「現在の実装範囲」は"できること一覧"、`design_notes.md` は"決定と未決事項"。
ルールそのものの定義はここに集約します。

## 1. 基本パラメータ

**リソース**（いずれも 0〜99）
| リソース | 初期値 | 最大 | 定数 |
| --- | --- | --- | --- |
| HP | 40 | 99 | `START_HP` / `MAX_HP` |
| MP | 20 | 99 | `START_MP` / `MAX_MP` |
| 金 | 20 | 99 | `START_GOLD` / `MAX_GOLD` |

**その他**
| 項目 | 値 | 定数 |
| --- | --- | --- |
| 手札の上限 | 9 枚 | `HAND_SIZE` |
| 所持カード上限（手札＋習得奇跡） | 18 枚 | `MAX_CARD_COUNT` |
| 属性 | 7 種 | `VALID_ATTRIBUTES` |

- カードを消費したら、手札を 9 枚まで補充する（所持上限 18 枚を超えない範囲で）。
- 属性は `none` / `fire` / `water` / `wood` / `earth` / `light` / `dark` の7種類のみ。

### リソースの支払いと肩代わり

金・MP・HP はコストや吸収の支払いに使う。

- 通常のカード使用コストは肩代わりしない。指定されたリソースが不足しているカードは選択・使用できない。
- 相手から金を奪うなど、本人の意思によらない**強制効果**だけ、不足ぶんを
  **`金 → MP → HP`** の順に繰り下げて肩代わりする（1:1 の等価交換）。
- 例：強制的に金を吸収されたが金が足りない → 不足ぶんをMPで払い、MPも足りなければHPで払う。
- 強制効果の繰り下げ順は固定（左が尽きたら右へ。HPから上へは戻らない）。
- **HP が最後の砦**。HP でも払い切れなければ HP が 0 になり脱落する。

MP / 金の初期値・最大値・プレイヤー状態・現在値の画面表示に加え、カード売買による
金の移動は実装済み。その他の入手・回復・吸収カード、MP / 金を直接増減させる効果は設計・実装待ち。

## 2. カードの構造

カードは `card_store.gd` の `_normalize_card` で必ず正規化される。プレイヤーが
自作したカードも、読み込み・投稿の時点で以下のルールに丸められる。

| フィールド | 取り得る値 | 既定 |
| --- | --- | --- |
| `type` | `weapon` / `armor` / `miracle` / `special` / `trade` | `weapon` |
| `effect` | `attack` / `buff` / `guard` / `reflect` / `heal` / `instant_death` / `buy` / `sell` / `exchange` | `attack` |
| `target` | `enemy` / `self` / `all_enemies` / `all_players` | `enemy` |
| `attribute` | 7属性のいずれか | `none` |
| `power` | 整数（回復の負数はダメージ扱い） | 10 |
| `chance` | 発動率 0〜100（%） | 100 |
| `effect_mode` | `all`（全効果発動） / `random_one`（1つ抽選） | `all` |
| `effects` | 効果エントリの配列（複合カード用） | 単一効果から自動生成 |
| `special_effect` | `double_attack` / `attribute_change` / `double_power` / `attribute_erase` / 空 | 空 |
| `special_attribute` | 属性変更で上書きする7属性のいずれか | `none` |
| `cost` | `{resource: none/gold/mp/hp, amount: 0〜99}` | `{resource: none, amount: 0}` |
| `price` | 売買時の価格（金 0〜99） | 既存カードはレアリティ基準で自動補完 |
| `tags` | `full_reflect` / `miracle_reflect` / `builtin` など | `[]` |
| `rarity` | 自動計算（下記) | — |

### 種類（type）の意味

`type` は効果・対象を制限しない（`special` でも `guard` を持てる等）。挙動に効くのは次の3点だけ：

- **`armor`** のみ、防御フェーズで `attack` 効果を「反撃」として使える。
- **`miracle`** は使っても消費されず「習得」される（→ 第10章）。
- レアリティからドロー山のコピー枚数が決まる（→ 第11章）。

### 複合効果（effects / effect_mode）

1枚に複数の効果を持たせられる。使用フェーズに合う効果だけが発動する（→ 第8章の表）。

- `effect_mode = all` … 条件に合う効果をまとめて全部発動する。
- `effect_mode = random_one` … `weight` の比で1つだけ抽選して発動する。

### 発動率（chance）

カード全体と、各効果エントリの両方に 0〜100% の発動率を持てる。
全体攻撃・全体回復は**対象者ごと**に、防具は**防具ごと**に個別判定する。

### 廃止された値の読み替え

- `effect: multi_attack` → `effect: attack` ＋ `target: all_enemies`。
- `target: all` / `ally` → `self`。
- `heal` だけのカードは属性相性に関与しないため `attribute` は `none` に固定。

## 3. ゲームの流れ（フェーズ）

```
action ──(攻撃/支援を出す)──▶ defense ──(防御 or パス)──▶ result ──┐
   ▲                                                              │
   └──────────────── continue_after_result ◀──────────────────────┘
                        （反撃・全体対象の続き・次ターンへ）
```

- **action**: 手番プレイヤーがカードを出すか、祈るか、パスする。
- **defense**: 攻撃/支援の対象が防御カードを出すか、パスする。
- **result**: 戦闘結果の演出。`continue_after_result` で次へ進む。
- **game_over**: 生存者が1人以下になったら決着（→ 第12章）。

手番は生存プレイヤーの間を順に回る。倒れた（切断含む）プレイヤーは飛ばす。

## 4. 行動フェーズ

手番プレイヤーができること：

### 4.1 攻撃のセット（攻撃／攻撃アップ）

`play_action_cards` は複数枚をまとめて「セット」として出せる。

- **攻撃カード（`attack`）は1回に1枚まで**。2枚重ねようとするとセット全体が弾かれ、何も消費しない。
- **攻撃アップ（`buff`）は何枚でも重ねられる**。威力は攻撃＋攻撃アップの合計。
- 攻撃アップは**単独でも攻撃**として使える（威力 = 攻撃アップの合計）。
- **攻撃アップは全体攻撃（`all_enemies` / `all_players`）には使用できない**。全体攻撃へ
  重ねた場合はセット全体を弾き、カードを消費しない。攻撃アップ単独でも全体は対象にできない。
- 攻撃・攻撃アップに、それ以外の効果（回復・防御など）は混ぜられない。
- 攻撃セットが奇跡カードだけで構成される場合は「奇跡」扱い。通常カードが1枚でも混ざると
  セット全体を「通常」扱いにし、奇跡反射ではなく通常反射の対象になる。

複数防具で防御するのと同じ操作感で、複数カードを重ねて1回の攻撃にする。

### 4.2 単発の効果

攻撃を含まないカードは**1枚だけ**単発で出す（`heal` / `instant_death` など）。
`guard` と `reflect` は防御フェーズ専用で、行動フェーズでは使用できない。

### 4.3 祈り（pray）

- 使用コストを払える攻撃カードも攻撃アップも、手札・習得奇跡に**ない**ときだけ祈れる。
  攻撃系カードを持っていても、すべてコスト不足なら祈れる。
- カードを1枚引いてターンを終える（所持上限に達していても、ターン終了としては成立する）。

### 4.4 使用コスト

カードには**使用コスト**を設定できる。コストは「リソース（金 / MP / HP）＋数量」で表す。

- カード種類による既定コストは設けない。奇跡を含め、作成者がカードごとに
  「なし／金／MP／HP」と0〜99の数量を設定する。
- コストは使用時に指定リソースから支払う。通常コストでは別リソースによる肩代わりをしない。
- 指定リソースが足りないカードは選択・使用できない。複数枚を同時に使う場合は合計コストで判定する。
- HPコストは現在HPと同値まで支払い可能。支払いでHPが0になった場合もカードは発動し、
  解決後に使用者が脱落する。

- コストが高いほどレアリティ評価は下がる。現在の評価式ではリソース種別を問わず、
  コスト1につき最終スコアを1点引く。

### 4.5 カード価格と取引

使用コストとは別に、すべてのカードは金0〜99の固有価格 `price` を持つ。
既存の保存データに価格がない場合は、読み込み時にレアリティ基準の初期価格を補う。
カード作成画面では価格を自由に設定できる。
自動補完値はコモン1／アンコモン5／レア10／レジェンダリー15／禁忌20。

- 売買カードは `type: trade` とし、`effect` の `buy` / `sell` / `exchange` で区別する。
- **買う**：相手を1人選び、その相手の手札からカードの数値ぶんをランダムに提示する。
  買い手は提示された全カードをまとめて購入するか、全部諦めるかの二択。
  一部だけは買えない。購入時は合計価格ぶんを買い手の金から支払い、
  売り手へ渡して、提示カードをすべて買い手の手札へ移す。金が不足している場合は買えない。
- **未使用の奇跡**：買うで提示されたカードが手札内の奇跡なら、表示価格にかかわらず無料。
- **売る**：カードの数値を売却可能な最大枚数とする。売るカードと、自分の手札から
  1枚以上・最大枚数以下のカード、相手1人を選ぶ。上限より少ない枚数でも確定できる。
  選択カードを相手の手札へ移し、合計価格ぶんを受け取る。
- **売買への防御**：「買う」「売る」は相手への攻撃として扱い、対象者に防御ターンが
  発生する。通常の防具・攻撃反射・奇跡反射は使えず、完全反射だけで返せる。
  「買う」が反射された場合は、完全反射した側が元の使用者から買う効果になる。
  「売る」が反射された場合は、選択されていた商品カードが元の使用者へ戻り、
  その合計価格だけを元の使用者から完全反射した側へ逆向きに徴収する。
- **押し売りの支払い**：売られた側は拒否できない。金が不足したぶんをMP、
  さらに不足したぶんをHPから1:1で支払う。HPまで尽きれば脱落する。
- **両替**：HP・MP・金は1:1で等価とし、3つの合計を変えない範囲で0〜99へ
  好きに配分する。UIではMPと金を `±1` / `±10` で動かし、HPは残りとして
  自動計算する。「カードを使う」で確定する。カードの数値は使用しない。
  HPを0にする配分も有効で、両替成立後にそのプレイヤーは脱落する。
- 取引カード自体にも通常どおり価格と使用コストを設定できる。

## 5. 攻撃の威力と属性合成

### 威力

出したカード（攻撃＋攻撃アップ）の `power` の合計が攻撃の威力になる。

### 攻撃側の属性合成（`_combined_offensive_attribute`）

- **光（`light`）はワイルドカード**。他属性と重ねると、その属性の攻撃になる。
- 光以外の属性が**2種類以上**混ざると、無属性（`none`）になる。
- 全部が光なら光。全部が無属性なら無属性。

## 6. 防御フェーズ

攻撃/支援の対象になったプレイヤーが応答する。

### 6.1 防具の選択

- **属性条件を満たす防具だけ**選べる（→ 第7章の属性防御表）。
- **ガード（`guard`）は複数重ねて出せ、防御値（`power`）は合算**する。
  防御値の合計が攻撃の威力以上ならダメージ 0。ダメージ = `max(0, 攻撃威力 − 防御値)`。
- **反射はガードと混ぜられず、単独で使う**（→ 6.2）。反射は数値を持たず、成立すれば全部返す。

### 6.2 反射（reflect）

反射は**防御フェーズでのみ使用できる**。
反射は「防具の一種」で、**数値（`power`）を持たない**。反射が成立すると対象は無傷で、
受けた攻撃を**丸ごと攻撃側へ返す**。1回の防御で**ガードと反射は混ぜられない**（反射は単独）。

反射は3種類あり、`tags` で区別する。

| 種類 | タグ | 返せる対象 | 属性ゲート | 返した攻撃の属性 |
| --- | --- | --- | --- | --- |
| 通常反射 | （なし） | 通常攻撃（光以外） | 攻撃を防げる属性のみ（第7章） | **無属性**化（※反射カードが光属性なら元属性を保持） |
| 奇跡反射 | `miracle_reflect` | 奇跡（`type: miracle`） | なし | 元の属性を保持 |
| 完全反射 | `full_reflect` | すべて（通常攻撃・光攻撃・奇跡・支援） | なし | 元の属性を保持 |

- **通常反射**：反射カードの属性が攻撃を防げる関係（例：火攻撃←水／光）のときだけ返せる。
  光攻撃・奇跡は返せない。返した攻撃は**無属性**になり、攻撃側は何でも防御でき、闇でも即死しない。
  ただし**反射カード自体が光属性**なら、元の属性を保ったまま返す。
- **奇跡反射**：奇跡専用の完全反射。属性を問わず奇跡を返し、元の属性を保つ。
- **完全反射**：属性を問わず何でも返す。回復・支援などの非攻撃効果を使用者へ返せる唯一の手段でもある。
- 属性を**保って**返した攻撃はその属性のまま攻撃側へ届く。**闇**を保って返すとダメージが通れば
  攻撃側も**即死**する。光を保って返すと、攻撃側は完全反射でしか受けられない。

この反射仕様は `game_rules.gd` / `card_store.gd` / テストへ反映済み。

### 6.3 反撃（counter）

`armor` かつ `attack` 効果を持つ防具で防御すると、防御解決後に「反撃」が用意される。
`continue_after_result` で、防御側から攻撃側への新たな攻撃として発動する。

## 7. 属性防御ルール

攻撃属性に対し、防御に使える／通用する属性は次の通り（`_attribute_can_defend`）。

| 攻撃属性 | 防げる防具の属性 | 備考 |
| --- | --- | --- |
| `none`（無） | すべて | どの防具でも防げる |
| `fire`（火） | `water`・`light` | |
| `water`（水） | `fire`・`light` | |
| `wood`（木） | `earth`・`light` | |
| `earth`（土） | `wood`・`light` | |
| `light`（光） | 通常防具は**なし** | 防具・通常反射では防げず、**完全反射だけ**が返せる |
| `dark`（闇） | すべて | ただしダメージが1でも通れば**即死** |

- **光攻撃**：通常の防具・通常反射では防御条件を満たさない（貫通）。**完全反射**だけが受けて返せる。
- **闇攻撃**：防具で**完全に防ぎ切れば無傷**だが、ダメージが少しでも残ると対象のHPを0にする（即死化）。
  反射した場合は、返した攻撃が**闇属性を保っていれば**攻撃側も即死する（光の通常反射／完全反射、
  闇の奇跡を返した奇跡反射など）。**無属性化する通常反射（非光）**で返すと即死しない（→ 6.2）。

複数属性の防具を混ぜると、表示上の防御属性は「`mixed`」になる。

## 8. 効果リファレンス

| 効果 | 内容 | 有効なフェーズ |
| --- | --- | --- |
| `attack` | 威力ぶんのダメージ | action（攻撃）／`armor`なら防御時の反撃 |
| `buff` | 攻撃威力を加算（攻撃アップ、単独でも攻撃） | action |
| `heal` | HP回復（負数はダメージ、最大HP=99まで） | action |
| `instant_death` | 対象のHPを0にする | action |
| `guard` | 防御値を用意（複数重ねて合算） | defense |
| `reflect` | 攻撃を丸ごと返す（数値なし。通常／奇跡／完全の3種、ガードと混在不可、→ 6.2） | defense |

フェーズごとに、そのフェーズで意味を持つ効果だけが発動する（複合カードは使い分けされる）。

---

## 9. 全体対象（all_enemies / all_players）

- **敵全体**（`target: all_enemies`）：効果の種類を問わず、敵全員へ順番に適用する。
- **全員**（`target: all_players`）：効果の種類を問わず、生存者全員（自分を含む）へ順番に適用する。
- 攻撃では各対象が個別に防御でき、発動率も対象ごとに振り直す。ただし `all_players` の
  使用者自身への処理では、防御カードを選べずそのまま解決する。
- どちらの全体対象にも攻撃アップは使用できない。

いずれも1人ぶんが解決するたびに `continue_after_result` で次の対象へ進む。

カード上の短縮表記は、敵全体（`all_enemies`）を **`全`**、敵味方を区別しない全員
（`all_players`）を **`（全）`** として区別する。

---

## 10. 奇跡（miracle）と所持上限

- `miracle` カードは使っても捨て札にならず、`learned_miracles`（習得済み奇跡）へ移り、
  以降**何度でも再利用**できる。
- 手札（通常カード）と習得奇跡を合わせた所持数は **18 枚が上限**。
- 上限に達しているときは、カードを消費しても補充が止まる。

## 11. レアリティとドロー山

### レアリティの段階

`common` → `uncommon` → `rare` → `legendary` → **`禁忌`（きんき）**

- **禁忌**は `legendary` の上位で、実質「制限枠」。**通常ルールでは使えない**
  （ドロー山に入らない）。**特殊ルールのときだけ**、制限付きで使用できる。

### 自動レアリティ（`auto_rarity`）

各効果エントリの寄与を合計し、カード全体の発動率・自傷補正を掛けて最終スコアを出す。

**効果ボーナス**（基礎点 = `|power|` ＋ 効果ボーナス）
| 効果 | ボーナス |
| --- | --- |
| `attack` | +0（`power` が基礎） |
| `heal` | +6 |
| `guard` | +8 |
| `buff` | +10 |
| `instant_death` | +60 |
| `reflect`（通常反射） | +12 |
| `reflect`（奇跡反射） | +22 |
| `reflect`（完全反射） | +35 |

- 反射は数値を持たないので、タグで決まる**固定値**を使う。

**属性ボーナス**（攻撃系 `attack` / `buff` に加算）
| 属性 | ボーナス | 理由 |
| --- | --- | --- |
| `none`・`fire`・`water`・`wood`・`earth` | +0 | 属性防御で受けられる |
| `light` | +8 | 通常防具で防げない |
| `dark` | +12 | 漏れれば即死 |

**その他の加点**
- 全体対象（`all_enemies` / `all_players`）：各効果に **+15**。
- 奇跡（`type: miracle`、何度も再利用できる）：**+12**。

**下げる補正**
- **発動率**：効果／カード全体の `chance`% を寄与に掛ける（50% なら半分）。

> 自傷減点はしない：`target: self` のカードも実際には**任意の相手へ撃てる**（自分にも他人にも）。
> 「自傷」は固定の性質ではなく、有害効果はプレイヤーが敵へ向けられるので、`target` に関わらず
> 素の威力で評価する（自分への即死カードは実質・敵への即死カードと同じ強さ）。

**合成**
- `effect_mode = all` は各寄与の合計、`random_one` は `weight` 比を発動確率とみなして按分する。

**特殊効果の補正**（→ 第13章、いずれも仮）
- **攻撃力倍**：そのカードの攻撃系寄与（`attack` / `buff`）を **×2**。
- **2回攻撃**：攻撃系寄与を **×2**（攻撃回数 +1 ぶんの実効威力）。
- **属性変更**：その特殊効果の属性ボーナス（光 +8／闇 +12 など）を加算。
- **属性消し**：**+8**（光・闇を無力化できる防御ユーティリティ）。
- **攻撃成功時デバフ／被弾時発動／その他**：効果内容しだい（未定、決まり次第スコア化）。

> レアリティは**1枚単位**で評価する。特殊効果は1枚1個なので、重ねがけ（複数カードの相乗）は
> スコアに含めない。各カードは自分の特殊効果1個ぶんだけ補正する。

### スコア → レアリティ

| 最終スコア | レアリティ | ドロー枚数（通常 / 特殊ルール） |
| --- | --- | --- |
| 60 以上 | `禁忌` | 0 / 制限（例：1枚） |
| 45〜59 | `legendary` | 1 |
| 30〜44 | `rare` | 3 |
| 16〜29 | `uncommon` | 5 |
| 15 以下 | `common` | 8 |

> よしなに置いた提案値。バランスは実装・プレイで調整する前提（`禁忌` の閾値・特殊ルールでの
> 制限枚数・各ボーナスは仮）。

### ドロー

- プレイヤーは作成済みカードからデッキを複数保存でき、対戦に使うデッキを1つ選ぶ。
- 同じデッキへ同一カードは重複して入れられない。デッキ枚数の上限は設けない。
- 接続時と使用デッキの変更時に、使用デッキをホストへ自動送信する。手動送信操作は設けない。
- 全プレイヤーの使用デッキを合流し、対戦中は1つの共通ドロー元として扱う。
- ホストがゲームを開始する時点で、共通ドロー元が5枚未満なら「カードが足りません」として開始しない。
- 各カードはレアリティに応じた重み（common 8 / uncommon 5 / rare 3 / legendary 1 /
  禁忌 0）を持ち、ドローごとに重み付きで抽選する。
- ドロー元は無限であり、カードを引いても候補から減らない。捨て札を山札へ戻す処理も行わない。
- 対戦用の共有カードは、個人コレクション（`cards.json`）とは分離される。

## 12. 勝敗・切断

- 生存者が**1人だけ**になったら、そのプレイヤーの勝利（`game_over`）。
- 生存者が**0人**なら引き分け。
- 試合中に切断したプレイヤーは脱落（HP0・生存フラグ解除）扱いにして、ターンを進める。

## 13. カードの特殊効果

一部のカードは、攻撃・防御などの**イベントに反応して発動する特殊効果**を持てる
（以前「エンチャント」と呼んでいたもの）。特殊効果は**カード作成時（カードエディタ）に
設定する、カード固有の定義**の一部で、`effect` や `attribute` などと同じくカードに焼き込む
（ランタイムで付け外しはしない）。**1枚につき特殊効果は1個まで**。発動タイミングで
3種類に分かれる。

攻撃系の特殊効果は、攻撃セットに入る各カード（攻撃カード・攻＋カード・攻撃奇跡など）に
付けられる。1枚1個でも、セットに複数のカードを重ねれば**各カードの特殊効果がまとめて攻撃に乗る**。
例：「水属性・攻撃力倍」のカードと「2回攻撃」のカードを一緒に出すと、水属性で威力2倍の攻撃を2回行う。

### 攻撃系（自分の攻撃時に発動）

- **攻撃成功時デバフ**：攻撃が通ったら対象にデバフを与える（内容はあとで決める）。
- **2回攻撃**：**攻撃回数を +1** する（1枚で2回、重ねがけで2枚なら3回、3枚なら4回…）。
  1回ぶんを解決するたびに、対象は改めて防御ターンを受ける。
  各攻撃でカード・効果の発動率を振り直す。追加攻撃から2回攻撃を再生成することはなく、
  最初に発動した枚数ぶんだけ有限回追加する。
  - **全体攻撃と併用**：攻撃回数のぶんだけ周回する（2回なら2周、3回なら3周…全員へ巡らせる）。
- **属性変更**：最終的な攻撃属性を、この特殊効果自身の属性に**上書き**する。
- **攻撃力倍**：**防御前の攻撃威力**を2倍にする（防御で軽減される前の値を倍化）。
  重ねがけは**乗算**（2枚で×4、3枚で×8 ＝ ×2ⁿ）。

### 防具系（自分の防御時に発動）

- **属性消し**：**攻撃側の属性**を消して無属性化する。相手の攻撃属性に関係なく**任意の防具で防御**できる。
  - **仕様**：本来防御不能な**光攻撃も防具で受けられる**ようになり、**闇攻撃も即死しなくなる**
    （属性消しは光・闇への数少ない対抗手段）。
- **被弾時発動**：攻撃を受けたときにカード（効果）を発動する。

### その他

上記2種に当てはまらないもの。中身は未定。

### 表示

- カードの特殊効果は、**ホバー時のカード詳細**に表示する。

レアリティ計算での評価は第11章「特殊効果の補正」を参照。

### 未確定（設計中）

- デバフ・その他特殊効果の**具体的な効果一覧**（決まればレアリティ補正も確定）。
