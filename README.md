# Draw Goffy

自分たちで描いたカードを持ち寄って遊ぶ、友人用のゴッドフィールド風カードゲームです。

## 開き方

1. Godot 4.x を起動する。
2. このフォルダをプロジェクトとしてインポートする。
3. `project.godot` を開いて実行する。

## 最初の遊び方

1. ホスト役が「ホスト開始」を押す。
2. UPnP に成功したら、表示された外部 IP とポート `32145` を参加者へ伝える。
3. UPnP に失敗したら、ホスト側ルーターで UDP `32145` を手動開放する。
4. 参加者はホスト IP とポートを入れて「参加」を押す。
5. 各自がカード画面でイラストを選び、カードを作る。
6. 参加者は「カードを送る（画像込み）」を押す。
7. ホストはカードが集まったら「ゲーム開始」を押す。全員の画面が自動でバトル画面へ切り替わる。

画像はパス文字列だけでなく、画像本体が参加者からホストへ送られます。
ホストは受け取った画像本体をカード情報と一緒に全参加者へ配り直します。

## ゲームルール

対戦ルールの確定仕様（HP・効果・属性防御・攻撃セット・全体対象・レアリティなど）は
[`docs/rules.md`](docs/rules.md) にまとめてあります。ここでは実装済みの機能だけを挙げます。

## 現在の実装範囲

- Godot 4 の最小プロジェクト。
- ホスト制 ENet 通信。
- UPnP による UDP ポート自動開放。
- 参加者からホストへのカード投稿と、ホストから全員への再配布。
- ゲーム内カードエディタと自動レアリティ計算。
- ランダム行動するデバッグ敵。
- 二段手札と、通常手札の後ろに並ぶ習得済み奇跡の表示。
- 攻撃カードと複数防具の対面表示、「ダメージ」「無事」の結果演出とアニメーション。
- 初期 HP 40、手札 9 枚の基本ルール。
- `attack`（攻撃）, `guard`（防御）, `reflect`（反射）, `heal`（回復）,
  `buff`（攻撃力アップ）, `instant_death`（即死）の効果。
- 1枚のカードへ複数用途を設定可能。攻撃／防御などは使用フェーズに合う効果だけが発動し、
  同じ用途の効果はまとめて発動する。比率を指定する「どちらか一方」の抽選にも対応。
- カードごとの発動率を0～100%で設定可能。全体・複数対象では対象者ごと、防具では防具ごとに個別判定する。
- 全体攻撃は「対象＝敵全体」で表し、1枚を敵全員へ順番に適用（各自が個別に防御可能）。
- 攻撃はカードのセットで解決。攻撃カードは1回に1枚までだが、攻撃アップ（`buff`）を
  何枚でも重ねて出せて威力を合算できる（防具を複数選んで防御するのと同じ操作）。
- 攻撃アップは攻撃カードと同じく単独でも攻撃として使える。
- 反射は数値を持たず、対象になったカードを使用者へそのまま返す。
  `attack_reflect`（攻撃反射）、`miracle_reflect`（奇跡反射）、
  `full_reflect`（全反射）の3種。防具との同時使用は不可。
- 返されたカードにも防具・反射を使用可能。全体攻撃への反射は、
  元の全体攻撃を全員ぶん解決してから1人への返しとして処理する。
- 事前に使った `guard` が攻撃解決時に適用される処理。
- 無・火・水・木・土・光・闇の属性防御ルール。
- 属性条件を満たす防具だけを使用できる防御選択。
- 異属性の攻撃・攻撃アップ併用時の無属性化、光属性を他属性の代用にする処理、
  光攻撃の防御不能、闇攻撃の致死処理。
- 正方形カード画像、属性色、右下のホバーカード詳細。
- 6効果（攻撃・攻撃アップ・防御・反射・回復・即死）と、1枚複合／発動率／抽選の処理。
- 攻撃セット・全体対象・属性防御・反射・反撃・事前防御・勝敗判定・切断処理。
- 対戦用の共有カードは個人コレクション（cards.json）と分離。
- 全カードに0〜99の価格を設定でき、売買カードの「買う」「売る」「両替」に対応。
